# Campus Voice — Student Feedback Portal

A frontend-only class project made with HTML, CSS and simple JavaScript.

## Files
- `index.html` — all pages/UI
- `style.css` — responsive styling
- `script.js` — feedback, login, image preview, search/filter, dashboard, analytics and localStorage

## Demo admin login
Username: `admin`
Password: `1234`

## How to run
1. Put all three files in the same folder.
2. Open `index.html` in Google Chrome.
3. Student: click **Give Feedback**.
4. Admin: click **Admin Login**.
5. Use the demo login above.

## Important
This version is frontend-only. Feedback is stored in the browser's `localStorage`, so it is suitable for a class demonstration but is not a real secure production system. The admin username/password are also demo credentials and should not be used for a real deployment.
